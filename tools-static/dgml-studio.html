DGML Studio

A browser-based editor for DGML (Directed Graph Markup Language), the graph format used by Visual Studio. Everything runs locally in your browser — files never leave your machine.

Mouse

Drag canvasPan
Wheel / pinchZoom
Shift + drag canvasBox-select
Double-click canvasAdd node
Double-click node / linkEdit label
Alt + drag from node (or Link tool)Draw a link
Click group +/− buttonExpand / collapse group
Right-clickContext menu

Keyboard

NAdd node (linked from selection)
F2Rename selected
DelDelete selection
Ctrl+GGroup selection
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+S / Ctrl+OSave / open
Ctrl+LRe-run layout
Ctrl+EToggle DGML source
F · + · −Fit · zoom in · zoom out
V / LSelect tool / link tool
Arrow keysNudge selected nodes

Supported DGML

Nodes, Links, Categories (incl. BasedOn, IsContainment), groups (Group="Expanded|Collapsed" with Contains links), Background/Stroke/Foreground/StrokeThickness/StrokeDashArray/Shape, conditional Styles (HasCategory, HasValue, comparisons), Bounds, GraphDirection and Layout. Unknown sections are preserved on save.
